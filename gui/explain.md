## 这是什么

ADOFAI Studio 把一个音频文件自动转成 **ADOFAI（《A Dance of Fire and Ice》）谱面**。

- **输入**：一首歌（mp3 / wav / ogg / flac 等）
- **输出**：一个 `.adofai` 谱面文件，直接放进游戏的自定义关卡目录就能玩

你不需要会写谱、不需要手动对点，工具会先「听懂」音乐里的节拍和旋律走向，再据此铺出地板。

## 怎么用（基本流程）

1. **导入歌曲** —— 在「生成谱面」页把音频拖进去（或点按钮选文件）。
2. **选参数** —— 选分离档位、踩点风格等（默认即可，后面再调）。
3. **生成** —— 点「生成」，等进度条走完（首次会加载模型，稍慢）。
4. **预览 / 微调** —— 到「工作台」试玩、看波形、调密度。
5. **导出** —— 导出 `.adofai`，丢进游戏就能跑。

> 提示：一首节奏清晰、各乐器分得开的曲子，出谱质量明显更好。

## 支持的音乐文件

- 常见格式都行：`.mp3` `.wav` `.ogg` `.flac` 等。
- 建议：单声道也行，但**立体声**通常分离效果更好；曲子越长，生成越久。
- 版权提醒：只对自己拥有版权或已获授权的音乐生成谱面。

## 常见问题

- **生成很慢 / 第一次特别慢？** 首次要加载模型到显存，之后就快了。
- **谱面踩点偏了？** 去「分离试听」听听鼓轨干不干净，换更高分离档位通常更准。
- **想要更密 / 更疏的谱面？** 工作台里调密度相关参数。
- **导出的 .adofai 游戏不认？** 确认放进了正确的自定义关卡目录；文件本身是标准格式。

**生成链路（音频 → 谱面）**

| 步骤 | 做什么 | 说明 |
|---|---|---|
| ① | 转 WAV（44.1k 立体声） | 统一格式，便于后续处理 |
| ② | 音源分离（多轨） | 把鼓、旋律、人声等拆开，各自检测 |
| ③ | 逐轨转谱 | 检测每轨的踩点（onset）与旋律走向 |
| ④ | 合并成多轨 JSON / MIDI | 把各轨结果拼成统一的中间表示 |
| ⑤ | 出谱（.adofai） | 按游戏规则把中间表示写成谱面文件 |

**已内置的核心能力（随主包分发）**

- 音源分离：基于 Roformer 架构的 6 轨分离模型（内置）
- 踩点检测：自训练 OSN1 onset 网络（内置）
- 出谱算法：第三方开源 ChartGenerator 引擎的适配版（内置）

**可选 / 规划中的能力（本版本未随主包提供）**

- 旋律转谱（MuScriptor）：可选扩展。模型权重体量大（数 GB），**不随主包分发**，需要的话单独获取后放入 `audio-sep/models/muscriptor/` 即可启用。
- OSU 扩散出谱：开发中，本版本暂未提供。

> 注：模型与引擎版本随更新变动，以程序内实际加载为准。
