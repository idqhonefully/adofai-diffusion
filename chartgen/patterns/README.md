### 三角形家族（`几种三角形.adofai`，权威）

注释约定：图形编号 `1`~`5`，`空` 当分隔。

| # | travel | 转角 | 位置 | |
|---|---|---|---|---|
| 1 | `60 · 60 · 60` | −120 −120 −120 | (0,0)(0,1)(.87,.5)(0,0) | ★位置也闭合 |
| 2 | `90 · 60 · 30` | −90 −120 −150 | (0,0)(0,1)(1,1)(.50,.13) | |
| 3 | `90 · 30 · 60` | −90 −150 −120 | (0,0)(0,1)(1,1)(.13,.50) | |
| 4 | `45 · 45 · 90` | −135 −135 −90 | (0,0)(0,1)(.71,.29)(−.29,.29) | |
| 5 | `90 · 45 · 45` | −90 −135 −135 | (0,0)(0,1)(1,1)(.29,.29) | 第 4 格落在斜边上 |

**两条不变量（5 个图形全中）：**

```
① travel 之和 = 180°    → 占「一拍」
② 转角之和   = −360°    → 朝向回正，走完还能顺着原方向继续
```

## 约定

```
1 个字符 = 15° = 1/12 拍          一拍 = 12 个字符
X = 按一下，· = 空拍
两个 X 之间隔 k 个字符 → 这一格 travel = k × 15°
```

角度由 travel 反算：`a[k] = (a[k-1] + 180 - travel[k]) % 360`，`a[0] = 0`。

**分隔格的判定**：段尾正好 `180°` 才算分隔；否则整段都是图形本体
（用户写的图形第 3 个 travel 是 30/60/45 这种，不是 180）。

## 轮数叠加

一个模板 = **一轮**。轮可以叠加 N 次直到覆盖完需要的音；
**每轮按顺序向外偏移**（`PositionTrack`，`justThisTile` 可 true/false，偏移可以是半格）。

## 模板数据结构

```
{ travel 序列, Twirl 位置, PositionTrack 偏移, 轮数 }
```

## 每段的 `EditorComment` 里都有什么

编号 · 乐理名 · `travel` 序列 · 记谱 · **转角序列 / 位置坐标 / 是否闭合**。

几何模型来自 `scrLevelMaker`：相邻两格恒距 1 格，**先按当前朝向走一格，再转**
（`turn = travel − 180`，`h[0] = 90°`）。

## 你要做的

1. 打开文件，按 `EditorComment` 找到每段
2. 在需要的地方插 `Twirl`（`{"floor": n, "eventType": "Twirl"}`，floor 从 0 数）
3. 段间那条 **180° 分隔格**不要摆 Twirl
4. **原地存回**，不用换地方

## 防覆盖

`tools/make_pattern_skeletons.py` 写入前检查文件里有没有 `Twirl`。
有 → 判定为你手改过的，`SKIP` 不动。已从清单移除的旧骨架也会被删掉（有 Twirl 的保留）。
